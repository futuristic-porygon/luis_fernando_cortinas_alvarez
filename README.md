Juego en Unity con login y registro, leaderboards con PlayFab y controles con joystick.

## Escenas

- `Login y Signin`: inicio de sesión y registro
- `Juego`: la partida
- `Leaderboards`: tabla de puntuaciones

## Cómo abrirlo

1. Instala Git LFS y clona el repo (`git lfs install` antes de clonar).
2. Abre la carpeta con Unity `6000.3.3f1`.
3. Abre `Assets/SCENES/Login y Signin.unity` y dale Play.
